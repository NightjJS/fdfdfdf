# Starfall (Звездопад)

Небольшой Fabric-мод для Minecraft **1.21.8** в духе Shooting Stars: ночью с неба падают звёзды,
из них добываются осколки, а из осколков куётся звёздное оружие и Сердце бессмертия.
Все текстуры — пиксель-арт 16×16 в ванильном стиле.

## Что добавляет мод

| Предмет / блок | Описание |
|---|---|
| **Упавшая звезда** (блок) | Появляется там, куда упала звезда. Светится на максимум, ломается железной киркой. Дропает 3–5 осколков (Fortune усиливает, Silk Touch даёт сам блок). |
| **Осколок звезды** | Базовый ресурс. 4 осколка ↔ 1 блок звезды. |
| **Ядро звезды** | 8 осколков вокруг алмаза. Чинит звёздное оружие в наковальне. |
| **Клинок звёздного света** | Меч чуть сильнее незеритового. Удар подсвечивает цель (Glowing) и рассыпает искры, ночью лечит владельца на пол-сердца за удар. |
| **Звездомёт** | Выпускает залп из трёх самонаводящихся звёзд (фейерверки), которые взрываются звездой на цели. Стрелка не ранит. Перезарядка ~1.25 с, 256 выстрелов прочности. |
| **Сердце бессмертия** | Лежит в любом слоте инвентаря. Когда вы должны умереть, тратит один из трёх зарядов, полностью лечит и даёт регенерацию, поглощение, сопротивление огню и урону. Перезаряжается крафтом с ядром звезды. Не спасает от `/kill` и пустоты. |

### Падающие звёзды

Ночью в обычном мире рядом с каждым игроком (32–80 блоков) примерно раз в 4 минуты рождается звезда:
она летит с высоты по диагонали, оставляя светящийся след, раздавливает всё на месте падения и
застывает блоком **Упавшей звезды**. Игроки поблизости получают сообщение с координатами.

Оператор может вызвать звезду вручную: `/starfall star`.

### Рецепты

```
Ядро звезды          Клинок звёздного света     Звездомёт
S S S                   C                        S F S     S — осколок звезды
S D S                   C                        S X S     C — ядро звезды
S S S                   B                        S C S     D — алмаз, B — огненный стержень
                                                           F — огненный шар, X — арбалет
Сердце бессмертия     Перезарядка сердца
G C G                 сердце + ядро звезды (без формы)     G — золотой блок
C T C                                                      T — тотем бессмертия
G C G
```

## Сборка

Нужны JDK 21 и интернет (Gradle скачает Fabric Loom, Minecraft и Fabric API).

```bash
./gradlew build
```

Готовый jar появится в `build/libs/starfall-1.0.0.jar`. Положите его в папку `mods` вместе с
[Fabric API](https://modrinth.com/mod/fabric-api) для 1.21.8.

Также при каждом пуше GitHub Actions (`.github/workflows/build.yml`) собирает мод и выкладывает jar
в артефактах воркфлоу — вкладка **Actions → Build mod → starfall-mod**. Пуш тега вида `v1.0.0` или ручной запуск
воркфлоу с галочкой *release* дополнительно создаёт релиз на GitHub с готовым jar во вложениях.

Запуск клиента для отладки: `./gradlew runClient`.

## Структура

```
  registry/ModItems, ModBlocks, ModItemGroups

  entity/StarBoltEntity.java      — самонаводящаяся звезда (на базе ванильной ракеты)
  event/ShootingStarManager.java  — спавн и сопровождение падающих звёзд
  event/ImmortalHeartHandler.java — отмена смерти
  event/StarlightBladeHandler.java— эффекты клинка
  event/StarfallCommands.java     — /starfall star
src/main/resources/
  assets/starfall/   — текстуры, модели, локализация (en_us, ru_ru)
  data/starfall/     — рецепты, лут-таблица, теги
```
