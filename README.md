# Starfall 2.0 — Celestial Edition (Звездопад)

Fabric-мод для Minecraft **1.21.8**. Ночью с неба падают звёзды, раз в несколько ночей небо
взрывается метеоритным дождём, на Небесном алтаре ждёт босс — Страж звёзд, а за Звёздными вратами
лежат **Бессмертные пределы**: парящие острова из звёздного камня под вечной звёздной ночью.
Все текстуры — пиксель-арт 16×16 в ванильном стиле, все звуки и музыка синтезированы специально для мода.

## Прогрессия

1. **Ночь.** Увидели вспышку в небе — бегите на координаты из чата: там лежит блок Упавшей звезды.
   Добудьте его железной киркой, получите осколки звезды.
2. **Ядро звезды** (8 осколков вокруг алмаза) открывает звёздное снаряжение: клинок, звездомёт,
   кирку, топор и броню.
3. **Небесный алтарь.** Поставьте его и ночью поднесите ядро звезды: с небес спускается
   **Страж звёзд**. Победите его и заберите **Печать Стража**.
4. **Звёздные врата** (обсидиан + ядра + печать). Поднесите ядро звезды — и вы в Бессмертных пределах,
   где растут астральные деревья, светятся звездоцветы и целестиновая руда, а вокруг парят Огоньки.
5. **Бессмертие.** Сердце бессмертия трижды отменяет вашу смерть и перезаряжается ядром звезды.

Всё это отмечается отдельной вкладкой достижений «Звездопад» (15 достижений).

## События

### Падающие звёзды
Ночью рядом с игроком звезда летит по диагонали со светящимся следом, раздавливает всё на месте
падения, бьёт ударной волной (урон + отбрасывание в радиусе 6 блоков), превращает землю вокруг в
светящийся **Звёздный прах** и застывает блоком. Над местом падения ещё несколько секунд стоит столб
света высотой в полсотни блоков — его видно издалека. Три вида:

| Звезда | Шанс | Дроп |
|---|---|---|
| Упавшая (золотая) | 70 % | 3–5 осколков |
| Лазурная | 23 % | 4–7 осколков + фрагменты кометы |
| Багровая | 7 % (в дождь — 45 %) | 4–7 осколков + небесная эссенция |

Иногда к упавшей звезде слетаются Звёздные огоньки. Звёздный компас автоматически перенастраивается
на последнюю упавшую звезду.

### Метеоритный дождь
Первой ночью и затем примерно каждую третью ночь (с 14500 по 18500 тик) начинается дождь: заголовок
на экране, фанфары, звёзды падают в десятки раз чаще, и большинство из них — багровые.

## Бессмертные пределы

Собственное измерение `starfall:immortal_realm`: парящие острова (генерация на базе ванильных
floating islands с собственными поверхностными правилами), вечная ночь (`fixed_time: 18000`,
ванильное небо со звёздами и луной), собственный туман, цвет неба, частицы звёздного света, фоновый
эмбиент и музыкальная тема.

Два биома:
- **Астральные луга** — астральный дёрн и почва, астральные деревья, поляны звездоцветов, редкие
  кристаллы, целестиновая руда и жилы упавших звёзд.
- **Целестиновые поля** — полированный звёздный камень с россыпями звёздного праха, много звёздных
  кристаллов и богатая целестиновая руда.

Прибытие — в святилище из звёздного кирпича с обратными вратами на (0, 100, 0). Врата в Верхнем мире
запоминаются: возвращение приводит к ним. При входе на экране появляется заголовок «Бессмертные пределы».

На островах встречаются **Упавшие обсерватории** — руины из звёздного кирпича с колоннами, фонарями,
алтарём в центре и сундуком (осколки, пыль, ядра, фрагменты, эссенция, саженцы, эликсиры, с шансом —
звёздный компас и пластинка). Шаблон хранится как NBT и ставится собственной фичей генерации.

## Существа

- **Страж звёзд** (босс, 320 HP, полоса босса). Кружит над целью, стреляет залпами самонаводящихся
  звёзд, каждые ~10 секунд вызывает на игрока багровую звезду. Ниже 50 % HP приходит в ярость: залпы
  чаще и больше. Дроп: Печать Стража, ядра звёзд, эссенция, фрагменты кометы, осколки.
- **Звёздный огонёк** — мирный светящийся дух. Живёт в Бессмертных пределах, прилетает к упавшим
  звёздам. Покормите осколком звезды — отблагодарит звёздной пылью.

## Предметы и оружие

| Предмет | Описание |
|---|---|
| Клинок звёздного света | Сильнее незеритового. Подсвечивает цель, ночью лечит владельца. |
| Молот кометы | Медленный тяжёлый удар: ударная волна бьёт и подбрасывает всех вокруг цели. |
| Звёздная кирка / топор | Инструменты выше незерита, чинятся ядром звезды. |
| Звездомёт | Залп из трёх самонаводящихся звёзд. |
| Скипетр звездопада | Призывает звезду на блок, в который вы смотрите (64 блока, перезарядка 8 с). |
| Звёздная броня (4 части) | Выше незерита. Ботинки — нет урона от падения; шлем — ночное зрение ночью; полный комплект — постоянный Звёздный свет и скорость ночью. |
| Сердце бессмертия | 3 заряда отмены смерти, перезарядка крафтом с ядром звезды. |
| Звёздный компас | Указывает на последнюю упавшую звезду, ПКМ — перенастроить на ближайшую. |
| Астральный плод | Еда с листвы астральных деревьев, даёт Звёздный свет. |
| Астральный саженец | Выпадает с астральной листвы; из него вырастает астральное дерево. |
| Пластинка «Starfall» | Музыкальный диск с темой Бессмертных пределов (дроп Стража и сундуков обсерватории). |
| Эликсир звёздного света | Зелье: неловкое зелье + звёздная пыль. Эффект **Звёздный свет** медленно лечит и осыпает искрами. |

## Блоки

Упавшая / Лазурная / Багровая звезда (анимированное свечение), Звёздный прах, Звёздный камень
(+ полированный, кирпичи, ступени, плита), Целестиновая руда, Астральная почва и дёрн, Астральное
бревно / доски / листва (настоящая листва: увядает вдали от стволов и роняет искры звёздного света) /
саженец, Звездоцвет (светится), Звёздный кристалл, Звёздный фонарь, Небесный алтарь
(анимированная печать), Звёздные врата (анимированный портал).

## Команды

Для операторов (уровень 2):

```
/starfall star [gold|azure|crimson]   уронить звезду рядом
/starfall shower [секунды]            запустить метеоритный дождь
/starfall guardian                    призвать Стража звёзд
/starfall realm                       телепорт в святилище Бессмертных пределов и обратно
```

## Сборка и CI

Нужны JDK 21 и интернет (Gradle скачает Fabric Loom, Minecraft и Fabric API).

```bash
./gradlew build        # jar в build/libs/starfall-2.0.0.jar
./gradlew runClient    # запуск клиента для отладки
```

В папку `mods` нужен [Fabric API](https://modrinth.com/mod/fabric-api) для 1.21.8.

GitHub Actions (`.github/workflows/build.yml`) на каждый пуш:
1. собирает jar и выкладывает его артефактом **starfall-mod**;
2. поднимает настоящий headless Fabric-сервер с модом и флагом `-Dstarfall.selftest=true`: самотест
   проверяет реестры, лут-таблицы, рецепты, достижения, роняет звезду и ждёт её приземления, спавнит
   Стража и Огонька, строит святилище в Бессмертных пределах и телепортирует туда сущность, запускает
   метеоритный дождь, после чего печатает `STARFALL SELFTEST PASSED`;
3. по тегу `v*` или ручному запуску с галочкой *release* публикует релиз с jar.

Ручной запуск с галочкой *classpath* выкладывает classpath компиляции в ветку `ci-classpath`
(удобно проверять компиляцию обычным `javac` без Loom).
